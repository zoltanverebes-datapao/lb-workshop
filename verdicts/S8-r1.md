  (drop the `env:` block dab7b17 added, restoring S6's contract) as an
  out-of-band prerequisite, since S8 cannot touch that file within its own

  out-of-scope contract failures in the full-gate check — that would be a
  change to `docs/rubric-base.md`'s S1 wording, dated and justified, not a
  silent exception.

  not S8-specific) means the "contract tests are frozen after commit" promise
  in `CLAUDE.md` currently has no git-level enforcement for *any* item, past
  or future: nothing under `tests/contract/` has ever actually been committed
  (`git ls-files tests/contract/` is empty at `HEAD`), so a future round could
  edit `S8.spec.ts` to make itself pass and no `git diff` would ever surface
  it. This is a structural gap a human should close (un-ignore the directory
  and commit the test files) before it is relied on again.
- Scope creep (`docs/glossary.md`, `.claude/agents/*.md`, `docs/rubric-base.md`)
  is all individually reasonable-looking maintenance, and the spec's Notes
  section discloses the `docs/rubric-base.md` change explicitly rather than
  hiding it — but disclosure in prose isn't the same as being inside
  `Scope: In` or the standing exception list, and the rubric's own wording is
  what I'm required to grade against.
- Every S8-specific criterion (C1-C24, and C25's *structural* Playwright
  proxy) passes cleanly, and independent verification of the code (pagination
  cursor encode/decode, keyset SQL with `LATERAL` join, environment guards,
  frontend hook/table/page components, error handler) shows careful,
  spec-faithful implementation with no shortcuts. The two failures recorded
  here are both about things outside the generator's own code quality: an
  unrelated file (`app.yaml`) blocking the unconditional full-gate check, and
  a handful of documentation/agent-definition files riding along in the diff
