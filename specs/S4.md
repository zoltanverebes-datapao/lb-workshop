# S4: Frontend scaffolding with Vite, React, and Tailwind CSS

Status: **IMPLEMENTED**

Inherits: `docs/conventions.md`, `docs/rubric-base.md`, `docs/glossary.md`

Depends on: S1 (repo root `.gitignore` already covers `node_modules/`)

## Goal

Create the `frontend/` directory so that all four frontend stages in
`scripts/verify.sh` pass (tsc, eslint, vitest, build). After this item, any
subsequent item can add pages, components, and API calls without setting up
tooling. The running dev server shows a placeholder page confirming the app
shell works.

## Scope

In:
- `frontend/` -- entire directory (new): Vite project, configuration files, minimal
  App component, one passing vitest test

Out:
- API connection, `fetch` calls, OpenAPI type generation (owner: first
  API-consuming item)
- Routing / React Router (owner: first multi-page item)
- Actual domain pages or components (owner: per-feature items)
- `/__test__/*` routes or fixture infrastructure
- Changes to `backend/`, `scripts/verify.sh`, or `playwright.config.ts`
- Changes to root `.gitignore` (`node_modules/` is already listed)

## Interface contract

This item has no API routes, no domain shapes, and no fixtures. The contract
is the file tree and the tool configuration.

### Directory layout (files the builder must create)

```
frontend/
  package.json
  tsconfig.json
  tsconfig.node.json        # (if Vite template produces one)
  vite.config.ts
  vitest.config.ts           # or vitest block inside vite.config.ts
  eslint.config.js           # flat config (ESLint 9)
  index.html
  src/
    main.tsx                 # ReactDOM.createRoot entry
    App.tsx                  # placeholder component
    App.test.tsx             # at least one passing test
    index.css                # Tailwind import (@import "tailwindcss")
    vite-env.d.ts            # Vite client types reference
```

### Dependencies (in `package.json`)

Production:
- `react`, `react-dom`
- `@tanstack/react-table`
- `@tanstack/react-query`

Dev:
- `typescript`
- `vite`, `@vitejs/plugin-react`
- `tailwindcss`, `@tailwindcss/vite`
- `eslint`, relevant eslint plugins for React + TypeScript
- `vitest`, `@testing-library/react`, `@testing-library/jest-dom`, `jsdom`
- `@types/react`, `@types/react-dom`

### TypeScript configuration

- `tsconfig.json` must set `"strict": true`.
- `"jsx": "react-jsx"` (not `"react"`).
- `"noEmit": true` so `npx tsc --noEmit` works as the type-check command.

### ESLint configuration

- Flat config format (single `eslint.config.js`).
- Must lint `.ts` and `.tsx` files.
- `npx eslint . --max-warnings=0` must exit 0 on the scaffolded code.

### Vite configuration

- `vite.config.ts` uses `@vitejs/plugin-react` and `@tailwindcss/vite`.
- `npm run build` produces output in `frontend/dist/`.
- Dev server port is not hard-coded (default 5173 for dev; tests use 5273 via
  Playwright config, but that is not this item's concern).

### Vitest configuration

- Uses `jsdom` as the test environment.
- `npx vitest run --reporter=dot` discovers and runs `*.test.tsx` files.

### App component

- `App.tsx` renders a single element with `data-testid="app-root"` containing
  the text "Lakebase".
- This is a placeholder; future items will replace it.

### App test

- `App.test.tsx` renders `<App />`, asserts the element with
  `data-testid="app-root"` is in the document and contains the text "Lakebase".

### package.json scripts

At minimum:
- `"build": "vite build"` (or `"tsc -b && vite build"`)
- `"dev": "vite"`
- `"test": "vitest run"`

## Rubric

Standing criteria in `docs/rubric-base.md` also apply. Number from C1.

- C1: `frontend/package.json` exists and lists `react`, `react-dom`, and
      `@tanstack/react-table` as dependencies.
      -- verified by: `test -f frontend/package.json && node -e "const p=require('./frontend/package.json'); const d={...p.dependencies,...p.devDependencies}; if(!d.react||!d['react-dom']||!d['@tanstack/react-table']||!d['@tanstack/react-query']) process.exit(1)"`

- C2: TypeScript strict mode is enabled.
      -- verified by: `node -e "const t=JSON.parse(require('fs').readFileSync('frontend/tsconfig.json','utf8').replace(/\/\/.*/g,'')); if(!t.compilerOptions.strict) process.exit(1)"`

- C3: `npx tsc --noEmit` exits 0 inside `frontend/`.
      -- verified by: `cd frontend && npx tsc --noEmit`

- C4: `npx eslint . --max-warnings=0` exits 0 inside `frontend/`.
      -- verified by: `cd frontend && npx eslint . --max-warnings=0`

- C5: `npx vitest run --reporter=dot` exits 0 inside `frontend/` and runs at least
      one test.
      -- verified by: `cd frontend && npx vitest run --reporter=dot 2>&1 | grep -E '1 passed|Tests.*1 passed'`

- C6: `npm run build` exits 0 inside `frontend/` and produces `frontend/dist/index.html`.
      -- verified by: `cd frontend && npm run build && test -f dist/index.html`

- C7: `App.tsx` renders an element with `data-testid="app-root"` containing the
      text "Lakebase".
      -- verified by: `grep 'data-testid="app-root"' frontend/src/App.tsx && grep 'Lakebase' frontend/src/App.tsx`

- C8: `App.test.tsx` exists and tests for `app-root` and "Lakebase".
      -- verified by: `grep 'app-root' frontend/src/App.test.tsx && grep 'Lakebase' frontend/src/App.test.tsx`

- C9: No `any`, `as any`, or `@ts-expect-error` in any `.ts` or `.tsx` file
      under `frontend/src/`.
      -- verified by: `! grep -rE ':\s*any\b|as any|@ts-expect-error' frontend/src/`

- C10: Reject -- the scaffolding does not contain API calls, fetch usage, or
       route definitions.
       -- verified by: `! grep -rE '\bfetch\(|axios|useQuery|createBrowserRouter|RouterProvider' frontend/src/`

- C11: Reject -- no files outside `frontend/` are created or modified (except
       `frontend/package-lock.json` which is auto-generated).
       -- verified by: inspection of the diff (evaluator checks `git diff --name-only` for files outside `frontend/`)

- C12: `frontend/dist/` is not committed (`.gitignore` or `frontend/.gitignore` excludes it).
       -- verified by: `echo "dist" | grep -qF "dist" && (grep -q 'dist' frontend/.gitignore 2>/dev/null || grep -q 'frontend/dist' .gitignore 2>/dev/null || grep -q '/dist' frontend/.gitignore 2>/dev/null)`

## Notes

- The root `.gitignore` already contains `node_modules/`, so `frontend/node_modules/`
  is covered. The builder may add a `frontend/.gitignore` for `dist/` or add `dist/`
  to the root `.gitignore` -- either approach is acceptable as long as C12 passes.

- Standing rubric criteria S2/S3/S4 (migration-related) do not apply to this
  item since no database changes are made. S5 (API types in sync) also does not
  apply since `frontend/src/api/types.ts` does not exist yet and is out of scope.

- The Playwright contract test stage in `verify.sh` will still run. Existing
  contract tests (S1-S3) must continue to pass. The builder should ensure
  `npm install` is run inside `frontend/` so the contract stage can find Playwright.
  However, Playwright itself is installed at the repo root level, not inside
  `frontend/`.

- Tailwind CSS v4 is used with the `@tailwindcss/vite` plugin. No
  `tailwind.config.js` or `postcss.config.js` is needed. The CSS entry point
  uses `@import "tailwindcss"` (not the v3 `@tailwind base/components/utilities`
  directives).

- `@tanstack/react-table` is installed now so it is available for future items.
  No table component needs to be rendered in this scaffolding item.
