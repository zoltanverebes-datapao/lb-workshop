# S1: Scaffold project with Python FastAPI structure, uv package manager, and git initialization

Status: **IMPLEMENTED**

Inherits: `docs/conventions.md`, `docs/rubric-base.md`, `docs/glossary.md`

## Goal

Establish the foundational `backend/` directory so that subsequent items have a
working FastAPI application they can extend. After this item, `uv run` commands
succeed, the dev server starts on the configured port, and the project is under
git version control with a sensible `.gitignore`. A health/ping endpoint is 
available to verify the application is running.

## Scope
In:
- `backend/` — directory structure, `pyproject.toml`, application entry point
- `.gitignore` — root-level gitignore for the whole repo
- git initialization (if not already a repo)

Out:
- Database connection, migrations (owner: future items)
- Docker / docker-compose setup (owner: future items)
- Frontend / `frontend/` scaffolding (owner: future items)
- `/__test__/*` seed routes (owner: first item that needs fixtures)

## Interface contract

### Directory layout

```
backend/
  pyproject.toml
  app/
    __init__.py
    main.py          # FastAPI app instance
    routes/
      __init__.py
      health.py      # health-check/ping route
  tests/
    __init__.py
    conftest.py      # shared pytest fixtures (empty body is fine)
    test_health.py   # tests for health route
.gitignore
```

### Routes

- `GET /api/health`  200 -> `{ "status": "ok" }`

This ping/health endpoint exists to verify the app starts and responds correctly.
It requires no authentication and is available immediately after the application 
starts.

### Dependencies in `pyproject.toml`

The project must declare at minimum:

| Package       | Purpose              |
|---------------|----------------------|
| fastapi       | web framework        |
| uvicorn       | ASGI server          |
| httpx         | async test client    |
| pytest        | test runner          |
| pytest-asyncio| async test support   |
| ruff          | linter               |
| mypy          | type checker         |

Additional libraries from the stack (SQLAlchemy, Alembic) are **not** added
in this item.

### Python version

`requires-python = ">=3.12"` in `pyproject.toml`.

### Application entry point

`uvicorn app.main:app --port 8000` starts the dev server on localhost:8000.
`uvicorn app.main:app --port 8100` is used for tests.
Both start from within the `backend/` directory.

### `.gitignore`

Must cover at minimum: `__pycache__/`, `.venv/`, `*.pyc`, `.mypy_cache/`,
`.ruff_cache/`, `.pytest_cache/`, `node_modules/`, `.env`,
`.claude/settings.local.json`.

### mypy configuration

`pyproject.toml` must include a `[tool.mypy]` section with `strict = true`.

### ruff configuration

`pyproject.toml` must include a `[tool.ruff]` section. The `select` list must
include at least `"E"`, `"F"`, `"I"` (pycodestyle, pyflakes, isort).

### pytest configuration

`pyproject.toml` must include a `[tool.pytest.ini_options]` section with
`asyncio_mode = "auto"`.

## Rubric
Standing criteria in `docs/rubric-base.md` also apply. Number from C1.

- C1: `pyproject.toml` exists at `backend/pyproject.toml` and declares
      `requires-python = ">=3.12"`.
      -- verified by: `grep 'requires-python' backend/pyproject.toml`

- C2: `uv sync` succeeds inside `backend/` and produces a `uv.lock` file.
      -- verified by: `cd backend && uv sync && test -f uv.lock`

- C3: `uv run ruff check .` exits 0 inside `backend/`.
      -- verified by: `cd backend && uv run ruff check .`

- C4: `uv run mypy .` exits 0 inside `backend/`.
      -- verified by: `cd backend && uv run mypy .`

- C5: `uv run pytest -q` exits 0 inside `backend/` and runs at least one test.
      -- verified by: `cd backend && uv run pytest -q | grep -E '^[0-9]+ passed'`

- C6: `GET /api/health` returns 200 with body `{"status":"ok"}` (ping endpoint).
      -- verified by: `cd backend && uv run pytest tests/test_health.py -q`

- C7: The app entry point is importable as `app.main:app`.
      -- verified by: `cd backend && uv run python -c "from app.main import app; print(type(app))"`

- C8: `.gitignore` exists at repo root and contains `__pycache__/` and
      `.claude/settings.local.json`.
      -- verified by: `grep '__pycache__' .gitignore && grep 'settings.local.json' .gitignore`

- C9: Reject -- requesting a non-existent route returns 404 (not 500 or 200).
      -- verified by: `cd backend && uv run python -c "
from httpx import ASGITransport, AsyncClient
from app.main import app
import asyncio
async def t():
    async with AsyncClient(transport=ASGITransport(app=app), base_url='http://test') as c:
        r = await c.get('/api/nonexistent')
        assert r.status_code == 404
asyncio.run(t())
"`

- C10: The project directory `backend/app/routes/` exists and contains
       `__init__.py`.
       -- verified by: `test -f backend/app/routes/__init__.py`

## Notes

- `scripts/verify.sh` already exists and expects `cd backend && uv run ruff check .`,
  `cd backend && uv run mypy .`, and `cd backend && uv run pytest -q` to work. It also
  expects a `frontend/` directory and Playwright. For this item, only the `backend:`
  stages need to pass. The full gate (S1 in rubric-base) will not be green
  until the web scaffolding item lands. The builder should verify the three
  `backend:` stages manually rather than running the full `scripts/verify.sh`.

- `uv.lock` should be committed (it is explicitly allowed by rubric-base S8).

- Do not add SQLAlchemy, Alembic, or any database driver. Those arrive with
  the database-connection item.

## Assumptions -- CONFIRM
- A1: The repo is not yet a git repository. The builder should run `git init` at the repo root.
- A2: `uv` is already installed on the builder's machine and available on PATH.
- A3: The health/ping endpoint lives at `/api/health` (not `/health`), consistent with the `/api/` prefix convention, and is the primary way to verify the app is running.
- A4: `scripts/verify.sh` is NOT modified by this item. The full gate will fail until `frontend/` exists; that is expected.
- A5: `backend/tests/` is the test directory (inside `backend/`), matching the convention in `conventions.md` (`api/tests/` in conventions refers to `backend/tests/` in this project).
- A6: No `APP_ENV` handling or `/__test__/*` route guard is required in this item. That arrives with the first item that declares fixtures.
- A7: `uv.lock` is committed to version control.
